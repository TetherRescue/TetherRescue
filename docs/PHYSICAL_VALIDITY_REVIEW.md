## 판정

현재 모델의 계산 일치·수치 안정성과 실물 정확성은 구분한다. 이 설계 자체의 예인·추력 측정 자료가 없어 실물 타당성은 미확정이다. 아래 자료로 계수를 자동 수정하지 않는다.

현재 선체 질량·부품 배치는 추정값이고, 최대 전진 50 N/대·후진 20 N/대도 config 주석상 추정값이다. 실제 제품보다 속도가 낮다는 것만으로 코드 오류 또는 보수적인 정확한 모델이라고 판정할 수 없다.

## 유사 질량·폭의 실제 예인 자료

Renau Martínez 외(2024)의 삼동선 설계는 길이 약 1 m, 폭 0.6 m, 배수 질량 약 20 kg, 시험 흘수 0.12 m다. 정수 예인실험의 실측값(EFD)은 아래와 같다.

| 속도 (m/s) | 논문 EFD 저항 (N) | 현재 배의 수평·평형 흘수에서 예상 저항 크기 (N) |
| --- | ---: | ---: |
| 0.8 | 3.7 | 6.89477 |
| 1.0 | 7.5 | 9.52308 |
| 1.2 | 11.9 | 12.51323 |

출처: [논문 원문 §3.1, §3.3, Table 2](https://doi.org/10.3390/jmse12020268). 현재 모델 열은 `5v + 4.523076923v²`를 계산한 값이며 새 예인 실험 결과가 아니다. 최신 main은 실제 잠긴 부피로 저항을 매 스텝 조절하므로, 자세·잠김이 변하는 전진 중에는 이 고정식과 달라질 수 있다.

삼동선과 상자 선체의 형상·흘수가 달라 차이를 현재 모델의 오차로 해석하거나, 이 표로 현재 Cd를 보정하면 안 된다. 해당 논문의 속도 범위를 넘어 4.3 m/s 성능이 검증됐다고 주장할 수도 없다.

## 앞뒤·좌우 저항 자료

CyberShip II는 길이 1.255 m, 폭 0.29 m, 질량 23.8 kg인 실험용 보급선 모형이다. 예인 실험으로 식별된 계수는 앞뒤 선형 0.72253, 제곱 1.32742, 세제곱 5.86643, 좌우 선형 0.88965, 제곱 36.47287이다(여기서는 저항 크기를 나타내는 양의 계수로 표기).

출처: [Skjetne·Smogeli·Fossen(2004), §2 및 Table 2](https://www.mic-journal.no/PDF/2004/MIC-2004-1-1.pdf). 앞뒤·좌우 각각 단독 이동하고 회전은 없는 경우의 실험 기반 식이다. 이 숫자는 Cd가 아니므로 config의 Cd와 직접 비교할 수 없다.

0.2 m/s에 식을 대입하면 현재 모델은 앞뒤 1.180923 N·좌우 3.784 N(비율 3.204), CyberShip II 식은 앞뒤 0.244534 N·좌우 1.636845 N(비율 6.694)이다. 후자는 원시 측정점이 아니라 실험에 맞춘 모델 계산값이다. 현재 배의 폭은 약 두 배이고 모델 항도 달라 그대로 이식하지 않는다. ‘좌우 저항은 앞뒤의 3배 초과’는 현재 단위 테스트의 조건이지 일반 물리 법칙이 아니다.

## 실물 검증에 필요한 후속 자료

- 물 담당: DRAG_LINEAR·DRAG_CD의 선정 근거와 적용 속도 범위.
- 로봇 담당: 추진기별 전진·후진 추력 대 속도·입력 자료 및 배터리·장비 실측 질량/위치.
- 해당 선체의 여러 속도별 예인 저항, 수상 전진 시 자세·흘수·속도 측정.
- 보정에 사용하지 않은 조건에서도 모델 예측과 실측이 맞는지 확인.
- 노즐 site의 잠김은 단일 기준점 검사다. 실제 흡입구 형상·환기·캐비테이션·속도에 따른 워터젯 효율을 검증하지 않는다.

실물 자료가 없는 항목은 ‘제안/추정, 실물 미검증’으로 유지한다. 팀 합의 전 통과 기준을 새 확정값으로 설정하지 않는다.
