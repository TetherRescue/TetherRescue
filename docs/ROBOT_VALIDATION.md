# 로봇 핵심 추진 검증

채연 직접 디버깅·터미널 실행 기록. 2026-11-15~16 대화에서 제공한 출력 기준.
아래 상세 수치는 최신 main 동기화 전 `1bfa303`의 코드에서 관측했다. `5d6e82e` 동기화 후 관련 테스트를 재실행한 결과는 [통합 보고서](WATER_INTEGRATION_VALIDATION.md)에 분리했다.

## 환경과 범위

- Conda `tether_rescue`, Python 3.12.14, MuJoCo 3.17.0, NumPy 1.26.4.
- `python -m pytest tests/robot/test_robot.py -v`: **27 passed in 0.71 s**(사용자 제공 출력).
- 전체 파일의 통과와 사용자가 각 변수를 직접 확인한 항목을 구분한다. 센서 시험도 자동 실행에는 포함되지만 전 항목을 디버거로 관측한 것은 아니다.
- 디버거의 실행 시간에는 입력 대기 시간이 포함되므로 성능 측정에 사용하지 않는다.

## Codex 비교 실행으로 확인한 전진 z속도 원인

추진력 작용점 z=−0.1 m, COM_z=−0.022857143 m로, 작용점이 무게중심보다 0.077142857 m 아래다. 100 N 합력이 앞머리를 드는 토크 약 7.714286 N·m도 만든다. 물·중력 없이 0.5초 후 앞머리가 약 17.62° 들리고 추력 방향에도 위쪽 성분이 생겼다.

메모리에서 추진기 작용점 높이만 COM 높이에 맞춘 비교에서는 vy=2.551020408 m/s, vz≈0, 기울기≈0이었다. 파일·전역 계수는 변경하지 않았다. 이 결과로 원인을 확인했으며, 실제 배의 추진기 위치를 고치라는 결론은 아니다.

## 잔잔한 물 전진 및 노즐 관측

물·중력 켬, 해류·파도 없음, 5초 무추력 정착 후 10초 최대 전진. 사용자 실행에서 전진 속도 약 4.302264 m/s, 앞머리 들림 약 0.57181°, vz는 출력 정밀도에서 0으로 안정됐다.

Codex가 추가로 매 스텝 노즐을 추적한 이전 기준 실행에서는 좌우 최소 잠김 0.02610936 m, 최대 0.03176982 m, 최종 0.02920695 m였다. 5001개 샘플 중 노출 0이며 노즐 차단을 켜도 같은 결과였다. 최신 main에서 최종 속도·자세·노즐 깊이도 재현됐다([통합 보고서](WATER_INTEGRATION_VALIDATION.md)).

## 판정과 남은 범위

기존 로봇 단위 테스트 및 핵심 추진 기능 검증 완료. 이는 실물 추력·최고속도·해상 구조 안전성의 검증이 아니다. 오른쪽 회전·오른쪽 노즐 차단의 대칭 직접 관측, 파도·접촉·견인 조건의 경로/정지 성능, 계수 근거와 허용 오차 합의는 별도로 관리한다.

`test_forward_at_yaw90_accelerates_world_y` 주석의 1.2 m/s는 당시 질량·추력 계산 결과 2.55102 m/s와 맞지 않았다. 판정에는 실행 시 계산한 expected를 사용했으며 팀원 코드는 수정하지 않았다.
