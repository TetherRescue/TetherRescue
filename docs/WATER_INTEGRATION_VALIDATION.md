## 판정 기준과 범위

- 접근: 기존 `arrived/READY` 판정 후 연속 5초 유지. 기존 설정은 연결점 간격 0.7±0.15 m, 상대속도 0.06 m/s 이하, 최소 형상 간격 0.1 m, 방향 오차 8° 이내 등이다.
- 미션: 기존 `COMPLETE` 판정 후 연속 5초 유지. 사람 진행 2 m 이상, 사람 속도 0.05 m/s 이하, 목적지 거리 0.20 m 이하, 잔여 장력 10 N 이하 등 기존 제어기·미션 조건을 그대로 사용한다.
- 미션 Watchdog도 그대로 사용한다: 접근 150초, 견인 100초, 전체 240초, 롤·피치 각각 60° 한계. 이는 잔잔한 물 시험용 기존 기준이며 새로 합의한 실물 안전 기준이 아니다.
- 배 단독 파도 측정은 유한 상태·경고 없음·30초 도달·전체 기울기 60° 미만을 수치 안정성 기준으로 사용했다. 임무 성공이나 수직 속도 0, 직선 유지까지 보장하는 기준이 아니다.
- 노즐의 ‘노출’은 측정 시점에 `수면 높이 − site_z <= 0`인 횟수다. 비율은 균일 시간 간격 샘플의 노출 비율이다. 흡입구 전체의 잠김이나 워터젯 효율 검증이 아니다.
- 최대 기울기는 선체 위쪽 축과 월드 수직축 사이 각도다. 롤·피치 각각의 최댓값과 다르다.

## 재현


측정 스크립트는 시나리오마다 JSON 한 줄을 출력한다. `--case calm_approach`, `calm_mission`, `waves_boat`, `waves_towing`, `waves_approach`, `waves_mission`으로 하나씩 재현할 수 있다. 완료 조건을 만족하지 못한 경우 종료 코드 1을 반환하고 실패 이유를 출력한다. 관측 결과를 통과시키기 위해 제어기·임계값을 완화하지 않는다.

## 해석 한계

- 파도는 수면 높이 함수다. 물 입자의 파도 속도·워터젯 성능 곡선·침수·흡입 환기·캐비테이션을 재현하지 않는다. 파도 시나리오 성공도 실제 해상 안전성의 증거는 아니다.
- 구조 장면은 구명환이 처음부터 `Lifebuoy(attached=True)`로 사람과 weld 연결된 상태다. 로프만 접근 후 연결된다. 실제 구명환 전달·잡기·착용 절차가 검증된 것은 아니다.
- 실물 속도·추력·저항 계수 근거 검토는 [실물 타당성 자료 검토](PHYSICAL_VALIDITY_REVIEW.md)에 분리했다. 해당 설계의 실측이 없어 실물 타당성은 미확정이다.
- 원격 CI·PR merge는 이번 로컬 검증과 별개이며 실행하지 않았다.

### 종합 판정

1. 잔잔한 물의 접근 및 전체 미션: 기존 완료 조건과 추가 5초 유지 만족.
2. 파도에서의 배 단독·사전 연결 견인: 제한된 수치 안정성과 힘 전달만 관측. 직진·구조 안전성은 미확정.
3. 파도에서의 연속 접근→연결→견인: **실패**. 기존 제어기·시간 제한을 그대로 적용했으며 결과를 통과시키기 위한 계수·임계값 수정은 하지 않았다.
4. 실제 선체와 추진기의 실물 타당성: **자료 부족으로 미검증**. 제조사·유사 논문은 참고 비교다.
