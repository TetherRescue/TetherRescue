### 복셀·시간 간격별 흘수 측정

실행 명령은 `python tests/measure_water_convergence.py`다. 실제 Water·Robot·build_world·advance_world를 사용하며 정수·해류 0·무추력·부가질량 꺼짐에서 수평 이론 흘수 위치보다 0.05 m 높게 시작했다. 각 경우 8초 진행하고 마지막 1초 평균을 비교했다. 복셀 수와 해류·부가질량 설정은 각 실험의 메모리에서 적용한 뒤 복원하며 config 파일은 변경하지 않는다. Python 3.12.14, MuJoCo 3.17.0, NumPy 1.26.4 기준이다.

| 복셀 분할 | dt=0.002 s 평균 원점 흘수 mm | dt=0.001 s | dt=0.0005 s | 수평 이론 흘수와 차이 mm (dt=0.002) |
| --- | ---: | ---: | ---: | ---: |
| 4×2×2 | 24.284815 | 24.284814 | 24.284814 | −0.230507 |
| 8×4×4 (현재 설정) | 24.511373 | 24.511372 | 24.511372 | −0.003949 |

수평 상자 이론 흘수는 **24.515322076 mm**다. 현재 설정에서 dt를 0.002→0.0005 s로 줄일 때 평균 원점 흘수 차이는 약 **0.000000507 mm**였다. dt=0.002 s에서 공간 해상도별 인접 차이의 크기는 약 0.226558 → 0.029068 → 0.014060 mm였다. 현재 8×4×4와 가장 촘촘한 32×16×16 사이 차이는 약 **0.015008 mm**다.

원점 흘수의 이론값 오차는 단조 감소하지 않았다. COM_x가 0이 아니어서 평형 피치도 약 −0.14~−0.16°로 달라졌으며, 수평 상자식과 기울어진 배 원점의 높이는 측정 정의가 다르다. 별도 출력한 잠긴 부피/(길이×폭)은 약 24.51530 mm로 이론 배수량과 가깝다. 부피 값은 마지막 스텝의 적분 직전 외력 계산 시점 값이다.

12개 경우에서 기록한 매 스텝 qpos/qvel/qacc는 유한하고 MuJoCo 경고는 0이었다. 마지막 1초 원점 흘수 변화 폭은 모든 경우 약 0.0000061 mm 이하였고 최종 선속도는 약 0.00023~0.00026 m/s였다. 이 측정에서는 시간 간격 민감도가 작고, 현재 설정과 고해상도 차이·수평 이론식 차이 모두 임시 1 mm보다 작다. 고해상도도 비교 측정값이며, 실측 정확도 및 다른 자세·파도 조건의 오차 범위는 미확정이다. 1 mm의 공식 채택은 팀 합의가 필요하다.

### 속도 측정

실행은 저장소 루트에서 `python tests/bench_speed.py`다. 물·배·사람·고정 연결 구명환·로프를 조립하는 기존 `build_surface_towing_world()`와 `advance_world()`를 사용한다. 해류·파도 0, 전진 명령 0.2, dt=0.002 s, 부가질량 기본 꺼짐이다. 화면·영상 추론·제어기 갱신은 측정에 포함하지 않는다.

각 반복에서 새 세계를 만들고 100스텝 예열한 뒤 1,000스텝을 측정했다. 조립·예열·결과 출력은 측정 시간 밖이다. 반복마다 종료 상태의 qpos/qvel/qacc 유한성과 누적 MuJoCo 경고를 검사한다. Python 3.12.14, MuJoCo 3.17.0, NumPy 1.26.4, WSL2 Linux의 Conda `tether_rescue`에서 3회 결과는 1887.936 / 1812.406 / 2063.687 steps/s, 중앙값 **1887.936 steps/s**, 실시간 배율 **3.7759**였다. 전체 테스트와 동시 실행한 관측값이며 장비 부하에 따라 달라진다. 성능 통과 기준은 팀에서 미정이다.

인자는 `--steps 1000 --warmup 100 --repeat 3`으로 지정할 수 있다. 실패 시 종료 코드가 0이 아니며, 수치 상태나 경고를 무시한 속도를 결과로 기록하지 않는다.

### 조건과 한계

- 이론 흘수 위치의 힘 비교는 잔잔한 물에서 수평 선체를 배치해 계산한 정적 검사다.
- 5초 후 흘수는 물과 배를 조립하고, 평형 위치보다 0.05 m 높은 곳에서 시작한 시뮬레이션 결과다.
- 테스트의 흘수 기록식은 `Hull.HEIGHT / 2 - 배 원점 z`다. 수면이 0 m이고 배가 수평인 조건의 깊이를 나타내며, 기울거나 파도가 있을 때의 국소 잠김 깊이를 그대로 나타내지는 않는다.
- `Expect.DRAFT_TOL`은 현재 `None`이다. `test_water.py`가 대신 사용하는 0.001 m는 팀 합의 전 임시 기준이며, 확정값으로 기록하지 않는다.
- 입력한 부품 질량·위치로부터 계산이 일치함을 확인한 것이며, 추정한 입력값의 실물 정확성을 검증한 것은 아니다.
- 45개 자동 테스트 통과와 개별 항목의 상세 물리 검토 완료는 구분한다. 자세 복원·저항·파도·접촉 등의 상세 검토는 남아 있다.
- 원격 CI 결과는 이번 작업에서 확인하지 않았다.

### 작업 방식

- 팀원의 물리 구현을 변경하지 않고 기존 테스트와 디버거로 확인했다.
- 실행 편의를 위해 Codex가 앞서 추가했던 `water.py` 진입 코드는 제거했다.
- `config.py`의 미커밋 수정은 사용자 요청으로 원복했다.
- 측정값은 대화와 디버거 출력에서 옮긴 기록이며, 별도 시계열 결과 파일을 생성한 것은 아니다.
