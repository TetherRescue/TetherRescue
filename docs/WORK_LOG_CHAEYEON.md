## 물 저항 상세 확인 기록

최신 main 반영 전 `1bfa303`의 기존 테스트를 사용자가 직접 디버깅했다. 다음 검사는 모두 continue 후 통과를 확인했다.

| 검사 | 확인값·결과 |
| --- | --- |
| 전진 1 m/s | 저항 −9.523076923 N, 기대값과 차이 0 N |
| 전진 2 m/s | 저항 −28.092307692 N, 1 m/s 대비 2.949919배 |
| 좌우 1 m/s | −34.6 N, 앞뒤 대비 3.633279배. 3배 초과는 기존 테스트 조건이지 보편 법칙이 아님 |
| 운동 반대 방향 | force×v, torque×ω의 각 성분이 음수. 난수 20개 조합 검사 통과 |
| yaw 90° 좌표 변환 | 월드 힘 (약 0,−9.52307692,0) N, x잔여 1.216×10⁻¹⁵ N |

### 실행 및 측정 근거

- 사용자 실행: `python -m pytest tests/test_water.py -v` → 45개 통과(제공된 터미널 출력 기준).
- 질량·무게중심: 사용자가 `Hull.MASS`, `Hull.COM`을 출력해 손계산과 비교.
- 흘수: Codex가 `test_drop_settles_at_hand_draft` 하나를 터미널 디버거로 실행하고, 흘수 기록 생성 직후 최종값과 마지막 1초 변화 폭을 읽음. 해당 테스트 통과.
- 부력·무게: 사용자가 `test_floats_at_hand_draft`의 assert 직전 중단점에서 아래 값을 직접 확인.

### 조건과 한계

- 이론 흘수 위치의 힘 비교는 잔잔한 물에서 수평 선체를 배치해 계산한 정적 검사다.
- 5초 후 흘수는 물과 배를 조립하고, 평형 위치보다 0.05 m 높은 곳에서 시작한 시뮬레이션 결과다.
- 테스트의 흘수 기록식은 `Hull.HEIGHT / 2 - 배 원점 z`다. 수면이 0 m이고 배가 수평인 조건의 깊이를 나타내며, 기울거나 파도가 있을 때의 국소 잠김 깊이를 그대로 나타내지는 않는다.
- `Expect.DRAFT_TOL`은 현재 `None`이다. `test_water.py`가 대신 사용하는 0.001 m는 팀 합의 전 임시 기준이며, 확정값으로 기록하지 않는다.
- 입력한 부품 질량·위치로부터 계산이 일치함을 확인한 것이며, 추정한 입력값의 실물 정확성을 검증한 것은 아니다.
- 45개 자동 테스트 통과와 개별 항목의 상세 물리 검토 완료는 구분한다. 자세 복원·저항·파도·접촉 등의 상세 검토는 남아 있다.
- 원격 CI 결과는 이번 작업에서 확인하지 않았다.

- 측정값은 대화와 디버거 출력에서 옮긴 기록이며, 별도 시계열 결과 파일을 생성한 것은 아니다.
